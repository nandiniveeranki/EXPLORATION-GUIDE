# AI-Powered Personalisation Module

## Overview
This module implements AI-based personalisation for the AI-Powered Exploration Guide.  
It uses machine learning techniques to analyze user interaction data and recommend relevant domains.

This module serves as the AIML component of the project and is integrated with the main web application.

---

## Objective
- To personalize user exploration using machine learning
- To demonstrate AIML integration with a web-based system
- To provide evaluatable ML output for academic assessment

---

## Machine Learning Approach
- Learning Type: Supervised Learning  
- Algorithm Used: Naive Bayes Classifier  
- Input: User interaction and domain preference data  
- Output: Recommended domain or category  

The model focuses on structured domain intelligence rather than popularity-based recommendations.

---

## Workflow
1. User interacts with the exploration platform  
2. Interaction data is collected  
3. Data is processed by the ML model  
4. Personalized recommendation is generated  
5. Output is used for evaluation and demonstration
