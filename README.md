# AI-Powered Personalised Exploration Guide

## Overview
The AI-Powered Personalised Exploration Guide is a web-based intelligent platform designed for structured and domain-centric exploration of India.  
Unlike conventional tourism or content platforms, this system focuses on knowledge-driven discovery supported by AI-powered personalization and chatbot assistance.

The project integrates frontend, backend, and machine learning components into a single unified system.

---

## Key Features
- Domain-based exploration (Agriculture, History, Medicine, etc.)
- AI-powered personalization using Machine Learning
- Chatbot for contextual assistance
- User authentication and feedback system
- Research-oriented exploration support
- Modular and clean project architecture
